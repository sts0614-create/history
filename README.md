# 역사 수업 실험실

2022 개정 교육과정에 맞춘 중·고등학교 역사 수업 자료실입니다. 학교급과 과정을 선택해 단원을 찾고, 공개된 수업 자료를 바로 활용할 수 있습니다.

## 교육과정 카탈로그

`index.html`에서 중학교 역사 1·2, 고등학교 한국사 1·2, 세계사와 문화 과정을 검색하고 학교급별로 필터링할 수 있습니다. 전체 28개 학습 주제를 싣고, 실제 공개된 자료와 준비 중인 주제를 구분해 표시합니다.

## 공개 자료

- `korea1/` 중학교 역사② Ⅰ. 국가의 형성과 발전 — 9차시
  - `index.html`: 단원 목차
  - `slides1~9.html`: 차시별 수업 슬라이드
  - `lesson.html?n=1~9`: 영상·사료·교사 발문·생각 질문·활동지
  - `game.html?g=l1…l9`: 수업 게임
  - `sim.html`: 한강 쟁탈전 역사 시뮬레이션
  - `teacher-kit.html`: 교사용 설계표
- `hangeul/sim.html`: 훈민정음 창제 원리 실험실

## 단원 콘텐츠 구성 목표

각 단원에 수업 슬라이드와 인쇄 가능한 학습지, 출처가 확인된 영상과 사료, 교사 발문과 생각 질문, 참여형 게임·시뮬레이션·시나리오를 연결해 제공합니다. 카탈로그에서 준비 중으로 표시된 주제는 아직 자료가 공개되지 않았습니다.

## 배포

GitHub Pages는 `main` 브랜치의 root를 사용합니다. 커밋이 반영되면 Pages 배포 작업이 자동 실행됩니다.
