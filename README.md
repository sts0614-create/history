# 역사 수업 실험실

2022 개정 교육과정에 맞춘 중·고등학교 역사 수업 자료실입니다. 학교급과 과정을 선택해 단원을 찾고, 공개된 수업 자료를 바로 활용할 수 있습니다.

## 교육과정 카탈로그

`index.html`에서 중학교 역사①·②, 고등학교 한국사1·2, 세계사, 동아시아 역사 기행, 역사로 탐구하는 현대 세계를 검색하고 학교급별로 필터링할 수 있습니다. `curriculum.js`에는 2022 개정 교육과정의 7개 과목, 32개 단원, 214차시의 목차와 성취기준 코드가 정리되어 있습니다.

단원 주소는 `unit.html?course=m1&unit=0`, 차시 슬라이드는 `class.html?course=m1&unit=0&lesson=0`, 인쇄용 활동지는 `worksheet.html?course=m1&unit=0&lesson=0&worksheet=1` 형식입니다. 번호는 0부터 시작합니다. 슬라이드는 기존 자료와 같은 1600×900 무대, 하단 조작 막대, 단계별 나타내기, 교사 메모(N), 전체 화면(F), 단원·활동지·다음 차시 링크를 사용합니다. 수업 흐름은 학습 목표, 생각 열기, 차시별 역사 내용, 자료 분석과 출처 탐색, 주제형 탐구 활동과 타이머, 내용 확인 문제, 서술형 질문, 정리, 출구 티켓으로 구성됩니다.

## 공개 자료

- `korea1/` 중학교 역사② Ⅰ. 국가의 형성과 발전 — 심화 자료 9차시
  - `index.html`: 단원 목차
  - `slides1~9.html`: 차시별 수업 슬라이드
  - `lesson.html?n=1~9`: 영상·사료·교사 발문·생각 질문·활동지
  - `game.html?g=l1…l9`: 수업 게임
  - `sim.html`: 한강 쟁탈전 역사 시뮬레이션
  - `teacher-kit.html`: 교사용 설계표
- `hangeul/sim.html`: 훈민정음 창제 원리 실험실

## 단원 콘텐츠 구성 목표

214차시 모두 차시별 역사 핵심 내용, 성취기준, 탐구 질문, 자료 분석 과제, 활동, 주제형 확인 문제, 출구 티켓을 담았습니다. `curriculum-content.js`는 차시마다 두 가지 핵심 사실을 설명하고, 확인 문제와 활동지는 그 내용을 사용합니다. 사료 원문·영상 대사를 임의로 인용하지 않으며 기관 링크는 자료 탐색의 출발점으로만 제공합니다. 실제 수업 전에 교사가 원자료·출처·저작권·학습 적합성 및 교과서의 인물·연도·용어를 확인하고, 학생에게 제시할 사료를 직접 선정해야 합니다. 성취기준 코드와 차시 범위는 교육부 고시 및 사용 교과서와 대조해 조정할 수 있습니다. 기존 `korea1/`의 9차시 슬라이드·활동·게임·시뮬레이션은 심화 자료로 유지하며, 생성된 역사② Ⅰ단원 자료실에서도 바로 이동할 수 있습니다.

공통 페이지는 빌드 과정 없이 HTML·CSS·JavaScript로 작동합니다. `curriculum.js`에서 과목·단원·차시와 성취기준을, `curriculum-content.js`에서 214차시의 핵심 역사 내용을 관리합니다. `curriculum-pages.js`는 기존 `korea1/ui.css`와 `korea1/deck.css`의 시각 규칙에 맞춘 단원·수업 슬라이드와 인쇄 활동지를 렌더링합니다.

## 이미지와 이용 조건

차시 슬라이드와 활동지를 열면 해당 차시의 제목으로 한국어 Wikipedia 자료를 찾고, 연결된 Wikimedia Commons 이미지의 라이선스 메타데이터를 확인한 뒤 허용된 이미지와 저작자·라이선스·Commons 원본 파일·관련 Wikipedia 문서를 표시합니다. 이미지 검색은 페이지를 열 때 실행되므로 인터넷 연결이 필요합니다. 적합한 공개 이미지가 없거나 Wikimedia가 요청을 제한하면 상태와 Commons 직접 검색 링크를 보여 줍니다.

공개 도메인, CC0, CC BY, CC BY-SA 등 재사용이 허용된 것으로 표시된 자료만 보여 줍니다. CC BY/CC BY-SA 자료는 저작자 표시 등 각 파일의 조건을 지켜야 하며, 이 자료실은 무조건적인 무저작권 이용을 뜻하지 않습니다. 문서 제목으로 자동 검색한 예시 이미지이므로 교사와 배포자는 사용 전에 원본 파일 페이지에서 최신 라이선스·저작자·이용 조건을 확인하고 수업 주제와 역사적 맥락에 적합한지도 점검하세요. [Wikimedia Commons 재사용 안내](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)를 참고하세요.
